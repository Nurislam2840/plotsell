01

Introduction

PlotSell is a premium, luxury-focused real estate website template designed for land sellers, plot developers, and real estate agencies. It comes with 18+ pages, 30+ features, and a complete design system built around deep forest green and luxury gold colors.

Key Highlights

  • Pure HTML, CSS, and JavaScript — no build step required
  • Fully responsive (mobile-first)
  • Dark mode with localStorage persistence
  • Multi-language toggle (English / Bengali)
  • Multi-currency switcher (USD/BDT/EUR/GBP/INR)
  • Interactive Leaflet map with plot markers
  • 360° Virtual Tour with Pannellum
  • Lightbox image gallery with keyboard navigation
  • EMI calculator + Amortization schedule + Chart
  • Investment calculator, Rent vs Buy, Unit converter
  • Mortgage pre-qualification quiz
  • Neighborhood insights with scores
  • QR code generator for each plot
  • PWA — installable as mobile app
  • Live search with Ctrl + K
  • Favorites + Compare (localStorage)
  • Custom cursor, toast, parallax, scroll progress
  • Cookie consent + Font adjuster + Reading progress

Setup & Installation

Option 1: Direct Open

Simply open index.html in any modern browser. Everything works without a server.

Option 2: Local Server (Recommended)

# Python 3
python3 -m http.server 8080

# Node.js
npx serve .

# PHP
php -S localhost:8080

Then open http://localhost:8080 in your browser.

Note: The template uses CDN resources (Google Fonts, Leaflet map, Pannellum, Chart.js, QRCode, Unsplash images). An active internet connection is required.

No Build Step Required

Unlike modern frameworks, PlotSell requires no npm install, no webpack, no compilation. Just edit and refresh.

Customization

Change Brand Colors

:root {
  --forest: #0B1F17;
  --gold: #C8A24A;
  --ivory: #F7F5EF;
}

Update Plot Data

Edit assets/js/data.js. Each plot structure:

{
  id: 1,
  title: "The Emerald Ridge",
  location: "Beverly Hills, California",
  size: "2.5 Acres",
  price: 4500000,
  priceLabel: "$4,500,000",
  image: "https://...",
  gallery: ["https://..."],
  features: ["Feature 1"]
}

WhatsApp Number

In assets/js/whatsapp.js:

const phone = '15551234567';

Contact Info

Edit footer in assets/js/components.js.
