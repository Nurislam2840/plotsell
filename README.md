# PlotSell — Premium Land Marketplace

A fully static, premium real estate website built with pure HTML, CSS, and JavaScript.

## Features
- 10 curated premium plots with detailed specs
- Advanced filtering & sorting (client-side)
- Dynamic plot detail pages
- Favorites (localStorage)
- Plot comparison (up to 3)
- EMI + Investment calculators
- Land size unit converter
- Mortgage pre-qualification quiz
- Site visit booking form with validation
- Live search (Ctrl+K)
- Dark mode toggle
- Interactive Leaflet map
- Lightbox gallery
- WhatsApp float button
- Multi-language (EN/BN)
- Toast notifications
- Custom cursor
- Parallax effects
- Fully responsive
